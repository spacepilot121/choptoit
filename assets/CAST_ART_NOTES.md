# Illustrated stage cast v2

Generated with the built-in image tool. Original PNG pixels are preserved; atlas JSON describes alpha-bounded frames for Phaser rendering.

- `cast-heads-v2.png`: twelve townfolk faces and four clergy faces; the helmeted face is also used for guards.
- `cast-bodies-v2.png`: ochre tunic, teal coat, clergy robe and guard armour.
- `cast-heads-v2.json` / `cast-bodies-v2.json`: frame metadata, generated by `scripts/map-cast-frames.cjs` (optional sharp dependency).

Legacy 87 head identifiers map to twelve illustrated townfolk faces. Legacy files remain available, but the main stage now uses the new cast. Four illustrated jesters in `cast-jesters-v2.png` and `cast-jesters-v2.json` now replace the old target holders; their target poles remain separate animated objects.
